# GrapeFPS
🍇 GrapeFPS — Aplicação de otimização para Windows desenvolvida em Python, com ferramentas para gerenciamento de cache do Discord, monitoramento de processos e recursos para facilitar a manutenção do sistema.




###GrapeFPS###
GrapeFPS é um projeto desenvolvido em Python com o objetivo de reunir ferramentas de otimização e gerenciamento do sistema Windows em uma interface simples e intuitiva.

🚀 Funcionalidades

🧹 Limpeza de cache do Discord: ferramenta para gerenciar arquivos de cache do aplicativo.

🎮 Monitoramento do Discord: identificação de processos relacionados ao Discord.

🖥️ Interface gráfica: painel organizado para facilitar o acesso às funcionalidades.

⚙️ Ferramentas de sistema: recursos voltados à manutenção e ao gerenciamento do computador.

🛠️ Tecnologias utilizadas

Python

Interface gráfica para desktop

Bibliotecas de gerenciamento e monitoramento de processos

🎯 Objetivo do projeto

O GrapeFPS é um projeto pessoal criado para praticar programação, desenvolver interfaces gráficas e explorar a automação de tarefas no Windows.
